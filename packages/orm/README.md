# @bunest/orm

Zero-dependency, Bun-native TypeORM-style ORM compatible with **all TypeORM database types** (powered natively by `bun:sqlite`, `Bun.SQL`, `fetch`, and `Bun.connect` TCP/TLS) and engineered specifically to eliminate every circular-class & nested-class failure mode in TypeScript / ESM / Bun.

## Supported Databases (100% Bun Native APIs — Zero npm DB Drivers)

| Database Type (`type`) | Dialect | Bun Native Engine | Notes |
| --- | --- | --- | --- |

| `"cockroachdb"` | `cockroachdb` | **`Bun.SQL`** (`adapter: "postgres"` wire) | `INT8 GENERATED BY DEFAULT AS IDENTITY`, `JSONB`, `$1..$n` |
| `"mysql"`, `"mysql2"`, `"aurora-mysql"` | `mysql` | **`Bun.SQL`** (`adapter: "mysql"`) | Native pool, TLS, `` `col` ``, `AUTO_INCREMENT`, `INSERT IGNORE` |

| `"mssql"`, `"oracle"`, `"sap"`, `"spanner"` | `mssql` / `oracle` / `sap` / `spanner` | Full SQL dialect compiler + `OrmDriverRegistry` | Exact `[col]` / `@p1` / `OUTPUT INSERTED.*` / `:1` / `OFFSET ... FETCH NEXT` / `MERGE INTO` / `THEN RETURN *` |

## Why TypeORM Breaks on Nested / Circular Classes — and How `@bunest/orm` Fixes Every Single One

| Failure Mode in TypeORM | Root Cause | `@bunest/orm` Solution |
| --- | --- | --- |
| `ReferenceError: Cannot access 'X' before initialization` on circular imports (`User <-> Post`) or forward same-file classes | `emitDecoratorMetadata` emits `typeof Target === "undefined" ? Object : Target`, throwing TDZ `ReferenceError` on uninitialized ES classes | **4 interoperable defenses:** (1) `entityRef<T>()` / string names + `import type`, (2) zero-overhead `Relation<T>` / `Nested<T>` type wrappers, (3) class-level `@HasOne` / `@HasMany` / `@BelongsTo` / `@ManyToManyOf` / `@Embeds` & `defineEntity()`, (4) optional Bun preload/build plugin (`@bunest/orm/plugin`) |
| Decorator evaluation order / `CircularDependencyException` | Eager metadata inspection & `new Target()` calls | **Two-Phase Lazy Metadata Graph (`compileMetadataGraph`)** with Proxy-based `inverseSide` capture |
| Nested `@Embedded` class crashes (deep nesting, arrays, self-recursive trees, mutual nested classes) | Unbounded column flattening & constructor errors | **Dual-mode `@Embedded` / `@Nested`** (`mode: "auto"`) + `safeInstantiate()` |
| Cyclic Foreign Keys fail DDL (`User <-> Profile`, `A -> B -> C -> A`, self-referencing `Category`) | Naive `CREATE TABLE` order | **Cycle-Aware `SchemaBuilder`** across all 11 SQL dialects |
| Infinite recursion on mutual `eager: true` relations | Unbounded JOIN / recursive loading | **Batched `WHERE fk IN (...)` Loader + Per-Query `IdentityMap`** with visited-edge & `maxEagerDepth` guards |
| Stack overflow / FK errors saving cyclic JS graphs | Unchecked recursion & wrong INSERT order | **3-Phase Cycle-Breaking `CascadeEngine`** |
| `JSON.stringify(entity)` throws `cyclic object value` | Circular JS references | **Cycle-Safe `serializeEntity()` & automatic non-enumerable `toJSON()`** |
