# ADR-013: NestJS v12.5.1 API Parity Contract, Built-in HTTP Security, Graph Inspection & `@bunest/axios`

- **Status:** Accepted
- **Date:** 2026-11-20
- **Supersedes / Relates to:** ADR-001, ADR-002, ADR-008, ADR-009, ADR-011, ADR-012

---

## Context

NestJS `v12.5.1` expanded its core and ecosystem surface with:
- Built-in HTTP security primitives (`enableCsrfProtection()` using Fetch-Metadata `Sec-Fetch-Site` + `Origin`/`Host`, Helmet-8 `useSecurityHeaders()`, and HMAC-SHA256 signed cookies via `cookies: { secret }` & `@SignedCookies()`).
- Extended HTTP/WebDAV method decorators (`@RequestMapping`, `@Search`, `@Propfind`, `@Proppatch`, `@Mkcol`, `@Copy`, `@Move`, `@Lock`, `@Unlock`, `@QueryMethod`), `@Render()` / `setBaseViewsDir()` / `setViewEngine()`, `routeConflictPolicy: { duplicate, shadow }`, `routeResolutionStrategy: "declaration" | "specificity"`, `return503OnClosing`, and `bodyParser: false`.
- Core DI & observability primitives (`INQUIRER`, `HttpAdapterHost`, `BaseExceptionFilter`, `ApplicationConfig`, `ModulesContainer`, `ExternalContextCreator`, `ModuleRef.introspect()`, `DiscoveryService.createDecorator()`, `IEntryNestModule` plain `ModuleMetadata` shorthand, `instrument: { instanceDecorator }`, `moduleIdGeneratorAlgorithm: "deep-hash"`, `SerializedGraph`, `GraphInspector`, `PartialGraphHost`, `preview: true` + `InitializeOnPreviewAllowlist`, and `repl()`).
- Companion ecosystem capabilities (`@bunest/axios` native `fetch()` `HttpModule`/`HttpService`, GraphQL `@Scalar`/`@Directive`/`@HideField`/`@Extensions`/`GraphQLSchemaHost`/`sortSchema`/Federation v2 Subgraph, Swagger `@ApiHideProperty`/`@ApiExtraModels`/`getSchemaPath`/`refs`/14 response shorthands, WebSockets `@Ack()`/`maxConcurrentMessages`/`useWebSocketAdapter()`, and Microservices `*RecordBuilder`/`CustomTransportStrategy`/`unwrap()`/`status`/`PreRequestHook`/`@GrpcStreamCall`/`inheritAppConfig`).

At the same time, Bunest MUST preserve all existing architectural invariants locked in ADR-001 through ADR-012.

---

## Decision

1. **Full Non-Breaking 22-Package API Surface Parity with NestJS `v12.5.1`:**
   - **Group 1 — 11 Core & DX Packages:** **610/610 ADR (100.0%)** direct exports (`610/613` = `99.5%` raw) and **2,476/2,476 ADR (100.0%)** public members (`2,476/2,500` = `99.0%` raw):
     - `@bunest/common`: **218/218 (100.0%)** exports & **1,079/1,079 (100.0%)** public members of `@nestjs/common@12.5.1` (including runtime `ShutdownSignal`, `ConfigurableModuleBuilder`, canonical zero-dep `ValidationPipe`/`StandardSchemaValidationPipe`/`ClassSerializerInterceptor`/`StandardSchemaSerializerInterceptor`, `MappedTypes`, full 52-method `HttpServer` interface, all 18 HTTP/WebDAV decorators, all 23 `HttpException` subclasses, and all NestJS v12 protected subclass hooks).
     - `@bunest/core`: **54/54 (100.0%)** exports & **311/311 (100.0%)** public members of `@nestjs/core@12.5.1` — **now including Bun-native `AbstractHttpAdapter`** (alongside `NestFactory`, `NestApplication`, `NestApplicationContext`, `NestContainer`, `MiddlewareBuilder`, `HttpAdapterHost`, `BaseExceptionFilter`, `ApplicationConfig`, `ModulesContainer`, `ExternalContextCreator`, `GraphInspector`, `SerializedGraph`, `PartialGraphHost`, `InitializeOnPreviewAllowlist`, `repl`, and route-conflict types).
     - `@bunest/http`: **13/13 ADR-001 (100.0%)** exports (`13/16` = `81.3%` raw) & **125/125 ADR-001 (100.0%)** public members (`125/132` = `94.7%` raw) — exports Bun-native **`AbstractHttpAdapter`** (`58/58` members) extended by `BunHttpAdapter` (`HttpServer` `52/52` members) plus Bun-native **`ServeStaticModule`** (`BunStaticLoader` over `Bun.file()`), with zero Express, Fastify, or `node:http` dependencies.
     - Remaining Group 1 packages: `@bunest/validation` **17/17 (100.0%)** (`73/73` members), `@bunest/mapped-types` **10/10 (100.0%)**, `@bunest/testing` **12/12 (100.0%)** (`78/78` members), `@bunest/config` **19/19 (100.0%)** (`30/30` members), `@bunest/swagger` **160/160 (100.0%)** (`527/527` members), `@bunest/axios` **5/5 (100.0%)** (`HttpService` `12/12`, `100%` Bun-native ADR-001), `@bunest/cli` **45/45 (100.0%)** (`18/18` members), `@bunest/security` **57/57 (100.0%)** (`179/179` members).
   - **Group 2 — 11 Ecosystem & Data Packages:** **475/474 ADR (100.2%)** (`475/488` = `97.3%` strict exact) across the 9 NestJS-paired packages: `@bunest/websockets` **19/19 ADR** (`19/20` raw), `@bunest/graphql` **142/142 (100.0%)**, `@bunest/microservices` **144/144 ADR** (`144/145` raw), `@bunest/events` **11/11 (100.0%)**, `@bunest/scheduler` **11/11 (100.0%)** + **83/83 `CronExpression`**, `@bunest/cache` **16/16 (100.0%)**, `@bunest/queues` **41/41 (100.0%)**, `@bunest/cqrs` **53/53 ADR** (`53/56` raw), `@bunest/observability` **38/37 ADR** (`38/46` raw) — plus Bun-native data packages `@bunest/sqlite` (**39 exports**, **7/7** audit bugs fixed) and `@bunest/sql` (**52 exports**, **8/8** audit bugs fixed).

2. **Preserved Bunest Architectural Invariants (Non-Negotiable):**
   - **ADR-001 (Bun-only):** Zero Express, Fastify, or `node:http` server layers in core. Bun-native `AbstractHttpAdapter` is exported from `@bunest/http` & `@bunest/core` and extended by `BunHttpAdapter` running directly on `Bun.serve({ routes, fetch, websocket, tls })` — achieving **54/54 (100.0%)** `@nestjs/core@12.5.1` export parity and full `instanceof AbstractHttpAdapter` compatibility while upholding ADR-001. `ServeStaticModule` likewise runs natively via `BunStaticLoader` (`Bun.file()`).
   - **ADR-008 (Promise-only pipeline):** Zero RxJS in core or `@bunest/axios`. `CallHandler.handle()` and `HttpService` methods return native `Promise<T>`.
   - **ADR-009 (Secure-by-default `ValidationPipe`):** `whitelist: true`, `forbidNonWhitelisted: true`, `forbidUnknownValues: true`, and `errorFormat: "bunest"` remain the defaults. NestJS v12 `errorFormat: "list" | "grouped"` and `maxErrorMessagesLength` are opt-in.
   - **ADR-012 (Fail-fast DI scope isolation):** `ScopeLeakException` remains fail-fast at bootstrap; no silent request-scope bubbling.
   - **Zero Hot-Path Regression:** When `enableCsrfProtection()`, `useSecurityHeaders()`, and `@Render()` are disabled, `executeFastSingletonRoute` keeps its exact zero-allocation fast path (`bun run bench`: **35,318 req/s** static GET = `100.5%` vs raw `Bun.serve`, **33,336 req/s** param GET + DI, **11,905 req/s** validated POST, **2,092,882 ops/s** hot DI).

3. **Zero-Dependency `@bunest/axios` Package (`packages/axios`):**
   - Provides NestJS `@nestjs/axios@12.0.2`-compatible `HttpModule` (`register` / `registerAsync`) and `HttpService` (`5/5` exports, `12/12` `HttpService` methods: `request`, `get`, `post`, `put`, `patch`, `delete`, `head`, `postForm`, `putForm`, `patchForm`, `interceptors.request`/`response`, `axiosRef`, `timeout` via native `AbortSignal.timeout`, retries, `validateStatus`, custom `fetch` injection) with **0 external npm runtime dependencies**.

4. **Strict Zero-Cycle, Zero-New-Deps & Release Gate Compliance:**
   - All **22 packages (388 src files)** MUST maintain **0 runtime circular imports**, **0 type-only circular imports**, **0 cross-package DAG cycles**, and **0 new external runtime dependencies** (only the 4 pre-existing runtime deps across the entire monorepo), enforced by `bun run verify:release` and full test verification (**3,529+ pass / 0 fail**).

---

## Consequences

- Existing NestJS v11/v12 applications can migrate to Bunest with minimal import and interceptor adjustments while gaining Bun-native performance, smaller footprint, and secure defaults.
- All new features are additive and opt-in, preserving 100% backward compatibility for existing Bunest apps and zero overhead when unused.
