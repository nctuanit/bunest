# ADR-020: Full Bun 1.4.5 Native Runtime API Alignment

- **Status:** Accepted
- **Date:** 2026-11-28
- **Extends:** [ADR-001](./ADR-001.md), [ADR-011](./ADR-011.md), [ADR-016](./ADR-016.md), [ADR-017](./ADR-017.md), [ADR-019](./ADR-019.md)

---

## 1. Context

Following [ADR-016](./ADR-016.md) (19-package consolidation), [ADR-017](./ADR-017.md) (zero external runtime deps & 2-file `node:*` quarantine), and [ADR-019](./ADR-019.md) (native Bun Workers), an end-to-end audit against Bun 1.4.5's runtime API surface (`https://bun.sh/docs/runtime/bun-apis`) identified remaining HTTP hot-path overhead, duplicated JS utilities, and unexploited Bun 1.4.5 native APIs across the monorepo.

---

## 2. Decision

Bunest aligns its runtime, HTTP/WebSocket pipeline, storage, mail, observability, AI/Elasticsearch/testing utilities, and CLI directly on Bun 1.4.5 native capabilities while maintaining **0 external runtime dependencies** and **100% NestJS conformance parity**:

### 2.1 HTTP & WebSocket Hot Paths (`@bunest/core/http`, `@bunest/core/ws`)
- **Zero-Promise `Bun.serve({ routes })` dispatcher:** `safeHandler` in `BunHttpAdapter` MUST NOT be declared `async` so synchronous fast-singleton routes return `Response` directly to Zig `Bun.serve`.
- **Zero-microtask `Bun.peek()` fast path:** `executeFastSingletonRoute()` checks `Bun.peek.status(result) === "fulfilled"` to unwrap already-settled `Promise` values synchronously.
- **SSE idle timeout protection:** `@Sse()` handlers invoke `server.timeout(req, idleTimeoutSeconds ?? 0)` so Bun's default 10s HTTP `idleTimeout` never severs quiet event streams.
- **Zero-copy `sendfile()` for `StreamableFile`:** When `!forceChunked && source instanceof Blob` (including `Bun.file(...)` `BunFile`), `response-serializer.ts` passes `source` directly to `new Response(source, { status, headers })`.
- **`Bun.serve` & `Server` surface:** Forward `ListenOptions.unix` (Unix domain sockets), invoke `server.closeIdleConnections()` on shutdown, expose `reloadRoutes()` via `server.reload()`, and forward WebSocket `backpressureLimit`, `closeOnBackpressureLimit`, `sendPings`, `publishToSelf`, and `drain(ws)` (`OnGatewayDrain`).
- **Cookies (`Bun.Cookie` & `req.cookies`):** `RequestContext.signedCookies` reuses `this.cookies` (`req.cookies` `CookieMap`); `serializeCookie()` delegates to `new Bun.Cookie(...)` when `sameSite` is explicitly set while preserving Express/NestJS `SameSite` omission semantics when unset.
- **Async Zstd & Static Assets:** `CompressionMiddleware` reads `await response.bytes()` and offloads large `zstd` responses (`>= asyncThreshold`, default 16 KiB) to async thread-pool `Bun.zstdCompress()`. `StaticAssets` supports pre-compressed `.zst` siblings, streaming `HTMLRewriter` (`rewriteHtml`), and `Bun.embeddedFiles` fallback for compiled executables.

### 2.2 Core Primitives, Config, i18n & HTTP Client (`@bunest/core`)
- Export canonical Bun 1.4.5 primitives from `@bunest/core/common`: `uuidv5()` (`Bun.randomUUIDv5`), `nanoseconds()` / `nowUnixNanoBigInt()` (`Bun.nanoseconds`), `isDeepMatch()` / `matchesShape()` (`Bun.deepMatch`), `semverSatisfies()` / `semverOrder()` (`Bun.semver`), `parseJsonl()` / `parseJsonlChunk()` (`Bun.JSONL`), `indexOfLine()` (`Bun.indexOfLine`), `createByteSink()` (`Bun.ArrayBufferSink`), `wrapAnsi()` / `sliceAnsi()` / `formatColor()`, `isStandaloneExecutable()` / `listEmbeddedFiles()` / `findEmbeddedFile()`, and `ImageDimensionsValidator` (`Bun.Image`) + AVIF/HEIC/BMP/TIFF magic-byte sniffing.
- Upgrade `runSubprocess()` (Bun branch) to native `Bun.spawn(..., { timeout })` while retaining the `node:child_process` fallback in `fs-runtime.ts` for `apps/vscode-bunest` (Node Extension Host).
- Add `parseJson5Config()` (`Bun.JSON5`) & `.json5` / `Bun.embeddedFiles` in `JsonI18nLoader`, OS keychain secret config loader via `Bun.secrets`, and `HttpClient` support for `Bun.FetchSession` (auto-closed on `onModuleDestroy`), `fetch.preconnect()` + `Bun.dns.prefetch()`, and Bun `fetch` extensions (`unix`, `proxy`, `tls`, `decompress`, `verbose`).

### 2.3 Ecosystem Packages & CLI
- **`@bunest/security` & `@bunest/orm`:** Synchronous Zig `Bun.CryptoHasher.hash("sha256", ..., "base64url")` in PKCE, `Bun.concatArrayBuffers` in JWS, and `Bun.sleep()` in ORM transaction retries.
- **`@bunest/storage` & `@bunest/mail`:** Streaming multipart uploads via `Bun.S3Client` `s3File.writer()`, zero-dep `.tar.gz` archives via `Bun.Archive` (with path-traversal rejection), zero-dep image inspection/transcoding via `Bun.Image`, `.md` mail templates via `Bun.markdown.html()`, `Bun.dns.resolveMx()` in `@bunest/mail/smtp`, and `Bun.indexOfLine()` in SMTP framing.
- **`@bunest/observability`:** Sub-microsecond monotonic `Span` timestamps via `Bun.nanoseconds()`, `JscHeapHealthIndicator` (`bun:jsc`), `DnsCacheHealthIndicator` (`Bun.dns.getCacheStats()`), `BunRuntimeMetricsCollector`, and zero-dep `UdpStatsdExporter` (`Bun.udpSocket()`).
- **`@bunest/elasticsearch`, `@bunest/ai`, `@bunest/testing`:** Async `zstd` & `Bun.JSONL` NDJSON support in Elasticsearch, deduplicated cookie parsing + `Bun.indexOfLine()` SSE + `parseJsonlStream()` (`Bun.JSONL.parseChunk`) in `@bunest/ai`, and `assertDeepMatch`/`matchShape` (`Bun.deepMatch`) + `createWebViewHarness` (`Bun.WebView`) in `@bunest/testing`.
- **`@bunest/cli`:** `build --compile --bytecode`, `--archive` (`Bun.Archive`), `explain --open` (`Bun.openInEditor`) & `ansi` markdown output (`Bun.markdown.ansi`), `info` `Bun.semver` compatibility + `Bun.inspect.table`, `mcp` `Bun.indexOfLine`, and OS keychain secret helpers (`Bun.secrets`).

### 2.4 Explicit Non-Goals (Preserving Existing ADRs)
- `Bun.FileSystemRouter` does NOT replace `@Controller()` + `Bun.serve({ routes })` ([ADR-003](./ADR-003.md), [ADR-011](./ADR-011.md)).
- `Bun.ModuleGraph` does NOT replace `@bunest/cli`'s zero-dep TS AST engine so `apps/vscode-bunest` remains runnable on Node.js Extension Host.
- `Bun.mmap` is NOT used for mutable files / static assets to avoid `SIGBUS` risks.

---

## 3. Normative Invariants

1. Zero external runtime dependencies and 2-file `node:*` quarantine ([ADR-017](./ADR-017.md)) MUST remain intact (`bun run verify:release`).
2. `bun:jsc` is permitted as a native Bun built-in module (parallel to `bun:sqlite`).
3. Every new public export MUST be re-exported from its package `src/index.ts` (or subpath index) and covered by unit/integration tests.
