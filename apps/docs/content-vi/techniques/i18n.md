# Đa ngôn ngữ (Internationalization - i18n)

**`@bunest/core/i18n`** cung cấp cơ chế phân giải ngôn ngữ theo từng request trên `AsyncLocalStorage`, tra cứu bản dịch định kiểu chặt chẽ hỗ trợ nội suy & chia số nhiều, định dạng số/ngày/tiền tệ bằng `Intl` gốc và thông báo lỗi kiểm chứng DTO được bản địa hóa—không có phụ thuộc runtime bên ngoài.

## Cài đặt

```bash
bun add @bunest/core
```

## Thiết lập Module

Đăng ký `I18nModule.forRoot()` với ngôn ngữ dự phòng (fallback), trình nạp từ điển/tệp và danh sách bộ phân giải ngôn ngữ theo thứ tự (`QueryLocaleResolver`, `HeaderLocaleResolver`, `CookieLocaleResolver`, `AcceptLanguageLocaleResolver`):

@@filename(app.module.ts)

```ts
import { Module } from "@bunest/core";
import {
  AcceptLanguageLocaleResolver,
  I18nModule,
  InMemoryI18nLoader,
  QueryLocaleResolver,
} from "@bunest/core/i18n";

@Module({
  imports: [
    I18nModule.forRoot({
      defaultLocale: "en",
      supportedLocales: ["en", "vi", "fr"],
      resolvers: [
        new QueryLocaleResolver("lang"),
        new AcceptLanguageLocaleResolver(),
      ],
      loader: new InMemoryI18nLoader({
        en: { greeting: "Hello, {name}!" },
        vi: { greeting: "Xin chào, {name}!" },
        fr: { greeting: "Bonjour, {name}!" },
      }),
    }),
  ],
})
export class AppModule {}
```

## Dịch thuật trong Controller & Service

Inject `I18nService` hoặc đọc ngôn ngữ của request hiện tại qua `@CurrentLocale()` / `I18nContext`:

@@filename(hello.controller.ts)

```ts
import { Controller, Get, Query } from "@bunest/core";
import { CurrentLocale, I18nService } from "@bunest/core/i18n";

@Controller("hello")
export class HelloController {
  constructor(private readonly i18n: I18nService) {}

  @Get()
  greet(@Query("name") name = "World", @CurrentLocale() locale: string) {
    return {
      locale,
      message: this.i18n.t("greeting", { args: { name }, locale }),
    };
  }
}
```

## Định dạng `Intl` & Kiểm chứng bản địa hóa

- Định dạng tiền tệ, ngày tháng, thời gian tương đối và danh sách bằng `Intl` gốc dựa trên ngôn ngữ đã phân giải của request.
- Tích hợp với [`@bunest/validation`](/techniques/validation) để tự động dịch thông báo lỗi kiểm chứng DTO theo từng request.
