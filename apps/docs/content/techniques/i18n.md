# Internationalization (i18n)

**`@bunest/core/i18n`** provides per-request locale resolution over `AsyncLocalStorage`, typed translation lookups with interpolation & pluralization, native `Intl` number/date/currency formatting, and localized DTO validation messages—with zero external runtime dependencies.

## Installation

```bash
bun add @bunest/core
```

## Module Setup

Register `I18nModule.forRoot()` with a fallback language, dictionary/file loader, and ordered locale resolvers (`QueryLocaleResolver`, `HeaderLocaleResolver`, `CookieLocaleResolver`, `AcceptLanguageLocaleResolver`):

@@filename(app.module.ts)

```ts
import { Module } from "@bunest/core";
import {
  AcceptLanguageLocaleResolver,
  I18nModule,
  QueryLocaleResolver,
} from "@bunest/core/i18n";

@Module({
  imports: [
    I18nModule.forRoot({
      fallbackLocale: "en",
      supportedLocales: ["en", "vi", "fr"],
      resolvers: [
        new QueryLocaleResolver("lang"),
        new AcceptLanguageLocaleResolver(),
      ],
      messages: {
        en: { greeting: "Hello, {name}!" },
        vi: { greeting: "Xin chào, {name}!" },
        fr: { greeting: "Bonjour, {name}!" },
      },
    }),
  ],
})
export class AppModule {}
```

## Translating in Controllers & Services

Inject `I18nService` or read the active request locale via `@CurrentLocale()` / `I18nContext`:

@@filename(hello.controller.ts)

```ts
import { Controller, Get, Query } from "@bunest/core";
import { CurrentLocale, I18nService } from "@bunest/core/i18n";

@Controller("hello")
export class HelloController {
  constructor(private readonly i18n: I18nService) {}

  @Get()
  greet(@Query("name") name = "World", @CurrentLocale() locale: string) {
    return {
      locale,
      message: this.i18n.t("greeting", { name }),
    };
  }
}
```

## `Intl` Formatting & Localized Validation

- Format currencies, dates, relative times, and lists using native `Intl` backed by the resolved request locale.
- Integrate with [`@bunest/validation`](/techniques/validation) to translate DTO validation error messages automatically per request.
